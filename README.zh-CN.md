# Probability Calibration Tool

**简体中文**

一个用于《The Binding of Isaac（以撒的结合）》抖音直播间积分玩法的 Windows 本地概率记录、分析与校准工具。

> 平台：**Windows x64**  
> 已验证环境：**Windows 11 x64**  
> 内置界面语言：**English**  
> 可选界面语言：**简体中文**

## 项目简介

Probability Calibration Tool 是一个当前为《The Binding of Isaac（以撒的结合）》抖音直播间积分玩法设计的本地 Windows 桌面工具。

在这一使用场景中，程序围绕不同角色和重复对局，记录用户在每局开始前作出的概率判断、相关赔率信息以及最终结果，并在这些记录的基础上提供一致的概率分析和长期历史统计。

对于每一局，用户首先选择对应角色，并在查看当前局正式历史分析之前独立给出自己的主观概率判断。程序随后可以：

- 对用户当前输入的主观概率进行分析；
- 根据已经积累的有效历史记录建立另一套独立的历史概率分析；
- 保存当前一局的输入、分析结果和最终结果，用于后续统计与校准。

### 核心设计原则

> **先记录判断，再观察历史；主观概率与历史概率始终保持独立。**

两套模型代表两个性质不同的信息来源：

- **主观概率**：用户针对当前这一局，在查看正式历史分析之前作出的概率判断。
- **历史概率**：根据当前角色和对应历史阶段中符合条件的既有记录得到的统计结果。

程序不会自动把两者平均、加权或合成为一个所谓的“综合概率”。

在一次正式计算之前，程序会限制可能影响用户原始判断的方向性历史信息，避免用户先看到历史结果，再反过来修改自己原本的主观概率。

历史记录也不是只要存在就一定作为有效概率结论使用。只有达到程序规定的统计条件后，历史模型才会作为正式历史概率分析显示。

### 它不是什么

Probability Calibration Tool 目前并不是：

- 《以撒的结合》的 MOD、修改器或游戏内辅助程序；
- 抖音客户端插件或直播间自动化程序；
- 自动操作或参与直播间积分玩法的程序；
- 自动替用户生成主观概率判断的预测系统；
- 自动根据历史记录修改用户主观概率的系统；
- 可以直接自行配置为任意游戏、任意规则的通用概率平台。

它是一个独立运行的本地记录与分析工具。

## 主要功能

程序当前围绕《以撒的结合》抖音直播间积分玩法中的角色和对局进行记录，并针对不同角色维护相应的历史记录和历史阶段。

- **主观概率分析**  
  记录用户在每一局开始时给出的主观概率，并基于这一判断生成独立的概率分析结果。

- **独立历史概率分析**  
  根据符合条件的历史记录建立另一套独立统计模型。历史结果不会自动修改、平均或替代用户的主观概率。

- **不确定性区间**  
  除了单一概率估计外，同时展示相应的不确定范围，避免只依赖一个看似精确的百分比。

- **赔率与 EV / S 分析**  
  根据用户输入的概率和赔率计算对应分析结果，并显示盈亏平衡阈值及相关状态。

- **历史数据成熟度判断**  
  历史数据只有达到规定的样本数量和不确定性要求后，才会作为有效的历史概率分析使用。

- **减少历史信息对初始判断的干扰**  
  在用户完成当前一局的正式计算之前，程序会限制可能影响主观判断的方向性历史信息。

- **按角色维护历史数据**  
  不同角色拥有各自对应的历史记录和统计信息。

- **历史阶段管理**  
  当直播间玩法环境或其他相关条件发生明显变化时，可以开始新的历史阶段，避免新的统计分析继续与已经不再具有可比性的旧阶段数据混合。

- **完整的单局记录**  
  保存每一局的输入、分析快照、最终结果以及是否计入后续历史统计等信息。

- **历史记录更正**  
  对已经完成的记录提供专门的更正流程，同时保留原记录及其审计关系，而不是直接覆盖既有历史。

- **未完成单局恢复**  
  如果程序在一局尚未完成时退出，可以在重新启动后继续处理原来的未完成记录。

- **本地备份与恢复**  
  程序维护本地数据备份，并提供相应的数据恢复机制。

- **本地数据存储**  
  核心记录保存在用户自己的计算机中，正常使用不需要云端账户保存数据。

- **多语言界面**  
  English 为程序内置语言，并可通过外部语言包使用简体中文界面。

## 下载与运行

### 系统与运行环境

- **操作系统架构：** Windows x64
- **已验证环境：** Windows 11 x64
- **安装方式：** 免安装发布包
- **Python：** 普通用户无需单独安装
- **开发环境：** 普通用户无需配置 Python、uv、Qt、PySide6、SciPy 等开发环境
- **网络：** 核心功能正常使用不依赖在线账户或远程服务保存记录

目前明确验证的是 Windows 11 x64。对于其他 Windows 版本，项目不作未经验证的兼容性保证。

### 下载

普通用户请前往项目的 **GitHub Releases** 页面下载最新正式版本。

Windows x64 主程序发布文件的命名格式为：

`ProbabilityCalibrationTool-<version>-Windows-x64.zip`

如果需要简体中文界面，还可以另外下载与主程序对应版本的语言包：

`ProbabilityCalibrationTool-LanguagePack-zh_CN-<version>.zip`

正式版本、历史版本以及各版本的更新内容均通过 GitHub Releases 发布。

> 普通用户不需要下载 GitHub 自动生成的 `Source code (zip)` 或 `Source code (tar.gz)`。这些文件是项目源码，不是可以直接运行的 Windows 发布包。

### 运行

1. 下载 Windows x64 主程序 ZIP。
2. 将整个 ZIP 完整解压到具有正常读写权限的位置。
3. 保持解压后的目录结构不变。
4. 打开解压后的 `ProbabilityCalibrationTool` 文件夹。
5. 双击 `ProbabilityCalibrationTool.exe`。

正式发布包已经包含运行程序所需的 Python 运行时和相关组件，普通用户不需要另外安装 Python 或配置开发环境。

程序采用免安装形式，不需要运行安装程序，也不需要通过命令行启动。

### 注意

`ProbabilityCalibrationTool.exe` 需要与发布包中的 `_internal` 目录保持原有相对位置。

请不要：

- 只把 `ProbabilityCalibrationTool.exe` 单独复制到其他位置；
- 删除 `_internal`；
- 随意移动 `_internal` 中的文件。

如果需要移动程序，请直接移动整个 `ProbabilityCalibrationTool` 文件夹。

## 简体中文语言包

Probability Calibration Tool 的程序内置语言为 **English**。

简体中文通过独立的外部语言包提供。即使没有安装任何语言包，主程序仍然可以正常使用 English 界面。

### 安装简体中文语言包

1. 在 **GitHub Releases** 中下载与主程序版本对应的简体中文语言包：

   `ProbabilityCalibrationTool-LanguagePack-zh_CN-<version>.zip`

2. 解压语言包，得到：

   `probability_calibration_tool_zh_CN.qm`

3. 将该文件放入：

   `%LOCALAPPDATA%\ProbabilityCalibrationTool\languages\`

   如果 `languages` 目录不存在，可以自行创建。

4. 启动 Probability Calibration Tool。

5. 打开：

   `Interface Language...`

6. 选择：

   `Simplified Chinese`

7. 点击：

   `Confirm`

8. 关闭并重新启动程序。

重新启动后，程序将使用简体中文界面。

### 语言包版本

建议始终使用与主程序来自同一 Release 的语言包。

不同版本的语言包不建议混用。旧语言包即使能够被较新的程序读取，也可能缺少后来新增或修改的界面文本。

### 切换回 English

再次打开 `Interface Language...`，选择 `English`，确认后重新启动程序即可。

界面语言切换在重新启动程序后生效。

## 基本使用

### 一局的基本流程

1. **开始新一局**  
   选择当前对局对应的角色。

2. **选择是否参考历史数据**  
   根据当前需要选择 `Use history` 或 `Do not use history`。

3. **填写局前预测输入**  
   输入：
   - 主观概率；
   - 胜方赔率；
   - 负方赔率。

   主观概率应表示你在查看当前局正式历史分析之前，对当前这一局作出的判断。

4. **执行计算**  
   点击 `Calculate`。

   计算成功后，程序会保存当前一局及其分析快照，并显示正式分析结果。

5. **查看分析结果**  
   程序会显示当前输入对应的主观概率分析。

   如果选择参考历史数据，并且当前角色的历史记录已经达到相应统计条件，还会同时显示独立的历史概率分析。

   > 主观概率分析与历史概率分析始终保持独立，不会自动合并成一个综合概率。

6. **等待当前一局结束并记录结果**  
   对局结束后，选择实际结果：
   - `Win`
   - `Loss`

   同时选择该记录是否：
   - `Include` — 计入后续历史统计；
   - `Exclude` — 保留本局记录，但不计入后续历史统计。

7. **完成本局并进入下一局**  
   确认并保存当前结果后，即可开始下一局。

### 最短流程

`选择角色`
→ `选择是否参考历史`
→ `输入主观概率与赔率`
→ `Calculate`
→ `查看分析`
→ `记录 Win / Loss`
→ `选择 Include / Exclude`
→ `完成本局`

### 常用快捷操作

- **Tab**  
  可以快速将焦点切换到当前界面的下一个可操作项。在连续填写一局的数据时，可以减少鼠标操作。

更完整的界面操作、修改与重新计算、历史阶段、记录更正、恢复等功能将在用户指南中详细说明。

## 数据与隐私

Probability Calibration Tool 的核心功能在本地运行，正常使用不需要注册账号，也不依赖云端账户或远程服务保存概率记录。

程序产生的用户数据与程序本体分开保存。

### 用户数据位置

用户数据保存在：

`%LOCALAPPDATA%\ProbabilityCalibrationTool\`

其中会保存程序运行所需的本地数据，例如：

- 单局记录和历史数据；
- 分析快照；
- 本地备份；
- 程序设置；
- 日志和诊断信息；
- 已安装的外部语言包。

程序 ZIP 的解压目录主要用于保存程序本体，而不是用户的长期数据。

### 删除程序与删除数据是两回事

Probability Calibration Tool 采用免安装的程序分发方式，但用户数据并不全部保存在程序文件夹中。

因此：

> **删除解压后的 `ProbabilityCalibrationTool` 文件夹，不会自动删除 `%LOCALAPPDATA%\ProbabilityCalibrationTool\` 中的用户数据。**

如果以后重新下载并运行程序，原有本地数据仍可能在兼容情况下继续使用。

如果希望彻底删除自己的程序数据，需要另外处理对应的本地用户数据目录。

### 备份与迁移

程序会维护本地备份，用于在数据出现问题时进行恢复。

如果需要：

- 重装 Windows；
- 更换电脑；
- 长期保存自己的历史记录；

不应只复制程序 ZIP 或 EXE，还需要另外处理自己的用户数据和备份。

完整的数据备份、恢复和迁移流程将在用户指南中说明。

### 隐私提示

数据库、备份和日志属于用户自己的本地数据。

如果需要将这些文件发送给其他人、提交到 Issue，或者用于故障排查，建议先确认其中是否包含自己不希望共享的历史记录或其他信息。
